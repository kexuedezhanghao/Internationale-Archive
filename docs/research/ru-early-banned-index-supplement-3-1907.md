# 1907年司法查封目录第三补编原件核读（2026-10-11；0.1.51）

本轮取得拉脱维亚国家图书馆数字对象`417231`的公开扫描。机构记录题名为《Алфавитный указатель книгам и брошюрам, арест на которые утвержден судебными установлениями》，出版地`[Санкт-Петербург]`，年代1907，语种俄文，原持有机构为Latvijas Nacionālā bibliotēka，形态为12页。对象页提供PDF`0309037488`，标示2.04 MB及MD5 `87d4a4ef9ab8248ab8270825b3616315`；这些是**机构给值**，本轮没有把它们冒充为独立下载复算结果。

## 题名叶直接证据

PDF1题名叶可直接读出：

- `ДОПОЛНЕНИЕ 3-Е`；
- 接`составленному в Главном Управлении по делам печати по 31-е марта 1907 г.`的索引；
- 分册范围`За август и сентябрь 1907 г.`；
- 定价`Цена 3 коп.`；
- 按出版事务总局命令印行，页底刊记`Типография Министерства Внутренних Дел. С.-Петербург. Фонтанка, 57.`。

这使Тимофеев2005年文章注14所列“第三补编／8—9月”首次获得本项目可直接核读的机构原件支持。它仍不把第一、第二补编或10—12月补编的存在性提升为原件事实。

## 与科茨目标的关系

本项目所追的科茨条目来自截至1907年3月31日编成的基准目录印刷第4页；本册则明确是8—9月新增事项的第三补编。即使第三补编自身也有印刷第4页，它不是1931年回忆所指的基准目录第4页，因此本轮没有取得科茨目标条目，也没有解决20页／38页候选身份、条目编号或原册关系。

下一步沿同一完整题名和机构数字对象结构追第一补编（4—5月）、第二补编（6—7月），同时继续单独追基准目录印刷第4页；不从本册缺少目标条目推断其他分册也无目标。
