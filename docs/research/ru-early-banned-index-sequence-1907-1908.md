# 1907—1908年司法查封目录版次关系核验（2026-10-11；0.1.49）

本次取得的是**国家图书馆的机构目录记录及馆藏状态**，不是1908年原件扫描。白俄罗斯国家图书馆记录`BY-NLB-rr20116150000`著录一册截至1908年1月1日的《Алфавитный указатель книгам и брошюрам, арест на которые утвержден судебными установлениями》，出版项`[С.Петербург, 1908]`，66页、17厘米。记录列馆藏号`В82486`与`09/2136`：前者在手稿、古籍和珍本阅览室显示一册可用且无需预订，后者在保存本书库显示一册不可用。

关键的版本说明写在题名中：这册1908年本是“替代出版事务总局1907年出版的同一索引及其补遗”的本子。它因此直接证明，到1908年本编成时，目录编制者把1907年的索引和补遗作为被替代的前一组出版物。记录入口：[国家图书馆目录 BY-NLB-rr20116150000](https://e-catalog.nlb.by/catalog/Record/BY-NLB-rr20116150000)。

## 20页本与38页本仍不可合并

上述版本说明没有逐项列出1907年索引与补遗的题名、截止日或页数，因而不能证明1969年书目所报的20页本是“正编”、38页本是“补遗”，也不能证明38页等于20页加18页补遗。38页本自身责任说明为编至1907年3月31日，更像累计截止日期，但在取得题名叶、补遗题名或明确的机构层级以前，只能把这一点当作待检假设。

精确检索截至1906年12月31日、20页的题名，本轮仍只回到已核的1969年Машкова后出书目，没有找到独立机构馆藏记录或公开扫描。ГПИБ系列节点再次在直接打开时出现`ERR_TOO_MANY_REDIRECTS`，没有继续反复试探，也没有据此判断无扫描、登录限制或权限拒绝。
