# 1907年38页查封目录馆藏核验（2026-10-11；0.1.48）

本次找到的是**可直接核验的机构馆藏记录**，不是1907年原件扫描。白俄罗斯国家图书馆目录的独立记录明确著录《Алфавитный указатель книгам и брошюрам, арест на которые утвержден судебными установлениями》，责任说明为内务部出版事务总局编至**1907年3月31日**，出版项`[С.Петербург, 1907?]`，38页、17厘米，馆藏号`В78671`。馆藏位置为手稿、古籍和珍本阅览室，目录本次显示一册、可用、无需预订。封面黏于装帧的馆注也可见。

记录入口：[国家图书馆目录 BY-NLB-rr20116140000](https://e-catalog.nlb.by/catalog/Record/BY-NLB-rr20116140000)。这些字段把1969年Машкова书目115页所报的38页候选落实到一条现存馆藏记录；它们仍不证明科茨条目位于印刷4页，也不证明1931年回忆所引《Список книг и брошюр, подлежащих аресту》就是这一册。

## 与20页候选的边界

截止1906年12月31日、[1907]年、20页的候选，本次未找到同等可核的机构记录或扫描。精确题名、刊记、馆藏号和印刷4页继续待取。因此不能用38页本替代20页本，也不能把1931年回忆的截止1907年1月1日和“第4页”移给38页本。

后续0.1.49另核[1908年66页替代本](ru-early-banned-index-sequence-1907-1908.md)：其机构题名明确说替代1907年的同一索引“及其补遗”，证明1907年存在索引／补遗序列；但该记录没有列出各分册页数，仍不能据20与38的算术关系判定两者为正编和补遗。

ГПИБ的[1907年系列节点](https://elib.shpl.ru/ru/nodes/66233)可由检索结果确认机构题名、出版者为Главное управление по делам печати／内务部印刷所，并提示分册另有扩展题名；但直接打开在本轮出现重定向循环，未取得分册图像或20／38页层级，故只记入口状态。没有绕过重定向、验证码或权限保护。
