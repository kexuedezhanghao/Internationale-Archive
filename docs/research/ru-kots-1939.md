# 科茨1939年六段本与三段颂歌核对

**已据1939年原册公开扫描核见科茨六段俄译，同册另有三段颂歌；两处首段用词不同。** 这补上了后续六段本的具体刊本见证，仍未解决1931／1937补译完成和最早发表年份。

底本：Эжен Потье：《Интернационал》，Москва：Гослитиздат，1939。馆藏[记录01005198800](https://search.rsl.ru/ru/record/01005198800)，[公开原页阅读器](https://viewer.rsl.ru/ru/rsl01005198800)。题名页与目录此前已核，本轮新增目视15幅，重点为歌词24–31页与册末生产说明；不称整书通读或完整逐字校勘。

## 六段全文与三段版本

| 书页 | 所见 | 核对范围 |
|---|---|---|
| 24／25 | 法／俄全文开头，篇首副歌及第1、2段 | 页码直接可见；俄文首段为разроем。 |
| 26／27 | 法／俄第3、4、5段及第6段前半 | 页码直接可见；第6段跨页，不重复计段。 |
| 28／29 | 法／俄第6段续完、篇末副歌及署名 | 这两页无清晰印刷页码，位置依连续页序及目录；俄文末署翻译А.Коц。 |
| 30／31 | 法／俄三段颂歌，分别对应1、2、6，三次副歌 | 页次依目录／页序；属于文字排版，不是乐谱。俄文首段为разрушим。 |

六段正文是48行主歌、篇首及篇末各一次四行副歌；法／俄均按[1,2,3,4,5,6]排列。三段颂歌为24行主歌及三次副歌。后者与六段本共享译者体系但有具体异文，不能仅靠删去第3、4、5段机械重构。这里只登记结构与限定读法，没有公开整段正文。

同册六段25页与三段31页首段分别为**разроем／разрушим**；两者副歌都采用现在时“Это есть”。1902年已核原刊是旧拼写разроемъ与将来时副歌。这组证据说明1939年一册内同时保存两种首段用词，不能据此给改词者或首次修订定年；也不能把1939年的三段文字替回1902年原页。

篇末的巴黎、1871年6月在鲍狄埃署名位置，是原作日期的刊载形式；不是科茨俄译完成日期。Б.В.Шварц的册末责任说明涉及装帧、题名、花饰和文字设计，与歌词末尾科茨译者署名分别处理。

## 三种日期必须分开

册末未编号生产说明直接记此书为Academia准备出版，编辑Г.Шенгели，并列：

| 事件 | 所见日期／信息 |
|---|---|
| 交付排印 | 1937年5月15日 |
| 签准印刷 | 1938年3月21日 |
| 题名页出版年 | 1939年，莫斯科Гослитиздат |
| 印数 | 10,000 |

这些是同一册所见的不同出版生产节点，没有因此建立“1938年另版”。1937年的交排记录给Academia出版通信路线增加具体时点，但没有逐页修订记录，不能推出此册六段歌词在交排日已经完全定稿，更不能据此裁决1931／1937补译之争。
