# 科茨选三段：自述出处及《火星报》副歌的区别

**已核1962年俄文原刊：它引述科茨解释为何只译三段，同时把1900年《火星报》的内容记为四行法语副歌和俄语散文释义。** 两项事实分别登记，不能由科茨的选段自述推出《火星报》刊过三段，也未建立这些材料与张光年1962年报告的转引关系。最早采用[1,2,6]组合的人或译本仍待核。

## 1962年《苏维埃音乐》原刊

Бонч-Бруевич档案，连至[目录记录01004734500](https://search.rsl.ru/ru/record/01004734500)与[公开目录扫描](https://viewer.rsl.ru/ru/rsl01004734500)。馆方著录目录共1–7卷，莫斯科1964–1987、2019；合并阅读器2652幅。本轮只核题名／目录与字母段导航抽样，**不是通读2652幅，也不是取得信件影像**。该目录没有可搜索文字层；检索接口的零结果不作为未藏证明。

**目录打字页399（扫描1531），第290盒、第10保存单位**，直接列Аркадий Яковлевич Коц致В. Д. Бонч-Бруевич的信，年份为**1930、1931**，数量栏为**12叶＋5个信封**，注明其中有带作者亲笔签名的打字信，并附1928年科茨照片一张。这里12是叶数，不能写成12封信。可据目录暂引“РГБ НИОР，ф.369，карт.290，ед.хр.10”；当前调阅标识、原件与逐封日期仍待核定。

这使1931年4月选段理由原信的追踪从泛泛查找收信人档案，推进为一个明确保存单位。**目录只列年份，没有月份、逐封日期、主题或引文**；它尚不能证明四月信、1930年7月28日信具体在此单位，也不能确定原信措辞。1939年43–44页的日期／选段理由证据继续保留为编者转引，不能升格为已核原信。相邻第11单位是科茨1930年致В. А. Поссе的打字副本，3叶，分别登记。

## 1939年书内的1907歌词与1906谱页影印（0.1.28）

同一1939年书新增目视扫描53、54、57–60。扫描54为后出的整页影印，图内原页码**11**，显示旧拼写三段主歌及三次副歌，对应[1,2,6]，首段可见**разроемъ**。1939年图注归给Д-н、圣彼得堡1907年，书题写**《Пролетарские песни》**；此前原书目写《Песни пролетариев》，保留差异，不只凭图注建立另一版。这里尚未取得1907年原册题名、版权页或独立馆藏扫描，也未完成整页逐字校勘；不新增歌词身份或全文。

扫描57–58是1939年图注所称1906年首份地下俄文《国际歌》乐谱的两页影印；“1906”“首次”均为1939年编者归属，原谱未独立取得，先不新增原始乐谱计数。扫描59直接可见印刷**47页**，给出取页线索《Первый сборник революционных песен》、“Вещего Баяна”、Д. А. Черномордиков。与1952年脚注的《10革命歌曲》题名分开，尚未确认是否同一出版物。扫描53无日期传单影印的作者／年代未定；扫描60核评论结尾及М. Друскин署名，无清晰印刷页码，不冒称直接核见48页。正文24–31页仍未读。

## 对现有结论的影响及下一步

1902年《Жизнь》第5期第201页已核见[1,2,6]三段正文，1939年评论又把科茨的选段理由引文明确系于1931年4月信；原信、1937或1957原文仍须取得后再核。现有材料既未核定全球首创者，也未证明三段组合由列宁选择。

下一步继续取1937年第10期213–216及第11期319–322页两篇自述、1957年109–110页（译歌缘起／选段理由分别核），并优先核**РГБ手稿部第369全宗、第290盒第10保存单位**中的1930–1931年信件，以查1931年4月选段理由原信；1931年第2期4–10页仍取，但改用于刊史及7月28日信核对。并取《Книжные новости》1937年第19期60–61页及1957年书信片段136／142／143页，核1930年6月／7月28日与1931年4–10／8–10两项差异；新增1959年Друскин16页及2012年文集〈История песен〉382–455页、1981年Дрейден55页、1907年诗集题名／歌词页取页，刊名、出版社和补译年份差异分开核。1948年回忆录原页、1950年法文演说册及1906年谱本另列待取。并保留1929年《Monde》第47期、1930年《新文艺》原刊、1939年俄书评论未读页、完整歌词摹录及出版生产记录进一步核对及1960年Друскин／Сохор两项待取。此批1960年目标未得，未以1967年不同著作替代。此前[法中出处续查](monde-1929-and-pottier-1939.md)和[首期原报核查](iskra-1900-1.md)的结论继续有效。
