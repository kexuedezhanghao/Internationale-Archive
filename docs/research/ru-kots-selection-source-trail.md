# 科茨选三段：自述出处及《火星报》副歌的区别

**已核1962年俄文原刊：它引述科茨解释为何只译三段，同时把1900年《火星报》的内容记为四行法语副歌和俄语散文释义。** 两项事实分别登记，不能由科茨的选段自述推出《火星报》刊过三段，也未建立这些材料与张光年1962年报告的转引关系。0.1.57又核Лебедев 1967年原期208—212页，其脚注明确把1931年文章第4／9页分别用于早期俄译史与科茨创作／选段叙述；仍是后出引文，不是1931原页。最早采用[1,2,6]组合的人或译本仍待核。
