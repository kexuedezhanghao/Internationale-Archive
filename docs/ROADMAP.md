# 收集进度与待办

更新日期：2026年10月30日。长期目标是尽可能完整地收集可验证的《国际歌》版本；当前公开目录有17项身份记录、12份历史正文，不代表独立译本总数或全部研究成果。

## 当前优先事项

1. **先推进日语原件。** 最新项目工作记录已完成俄语馆方申请路线准备，研究重心转向其他语言。先补1927年《労働歌及組合歌》的刊记和逐字转录，再分别定位1903年《労働世界》小塚空谷〈万国党の歌〉、1922年《種蒔く人》及1929年改译原页。每份分别核译者、首刊、段数、法／俄底本关系与权利依据。
2. **保留俄语核心缺口。** 1931年《На литературном посту》第2期4–10页、1937年自述、1957年诗集相关页、原信及出版审查案等继续待合法原件。馆方申请目前仅完成准备；没有因此认定原页已取得或问题已解决。最早采用[1,2,6]组合者仍未核定。
3. **补齐已知曲谱与中文待办。** 继续1888年狄盖特谱本数字化；补1962年中文具体修订者及转载依据、1922年报头与整版、其他已列中文原刊。已有文字校勘结论保留。
4. **扩展与去重。** 继续2022年史料书第三编及附录索引，逐组处理语言标签、译本身份和第三方许可。来源条目、刊本、独立翻译和录音分别计数。

1927年日语材料目前只在本次[交接摘要](research/progress-2026-10-30.md)登记定位及核读边界；尚未并入公开版本数据库，因此本轮17项身份／12份正文的数量不变。旧“俄语完成后才转日语”的先决顺序已被最新安排覆盖。
